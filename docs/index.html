Open source firmware automation for Linux

Connect a board. FlashBot builds, flashes, and verifies it.

FlashBot identifies the board you plug in, selects matching Arduino or PlatformIO firmware, uploads it, checks the result over the serial port, and records every run.

How it works

One pipeline from USB event to recorded result

Each stage reports its outcome. A run counts as successful only when the build, the upload, and every test pass.

  1. Detect

    udev hotplug events, with a polling fallback.

  2. Identify

    USB ID to board name, FQBN, and PlatformIO ID.

  3. Select

    Every sketch and environment that targets the board.

  4. Build

    arduino-cli or PlatformIO, skipped when unchanged.

  5. Flash

    Upload with retries where the platform needs them.

  6. Test

    Serial checks declared next to the sketch.

  7. Record

    Every run and failing stage in SQLite.

Features

Built for repeated flashing

For firmware development at a desk, teaching labs that flash many boards, and unattended flashing stations.

Arduino and PlatformIO

Arduino sketches build with arduino-cli; any directory with a platformio.ini is discovered automatically, with each environment offered for matching boards.

Automatic identification

Arduino, ESP32, and Raspberry Pi Pico boards are recognised from their USB ID. Anything else is registered once and remembered.

Incremental builds

A SHA-256 of every source file is kept per sketch and board. Unchanged sketches go straight to upload from their own build directory.

Serial verification

Declare send and expect steps in flashbot.json. FlashBot follows the board through re-enumeration and detects the baud rate from your code.

Unattended and CI

Flash several boards in parallel without prompts, as a systemd service or in Docker, and compile every target in CI with JUnit XML results.

Monitor, plot, report

A serial monitor with logging, a terminal plotter for numeric output, and a history report that shows exactly which stage failed.

Hardware

Works with the boards you already use

Any board supported by an installed arduino-cli core or PlatformIO platform can be built and flashed.

Generic USB-serial bridges such as the CH340 and CP210x are shared by many boards. User registrations take precedence over the built-in table, so a bridge can always be mapped to the board it is attached to.
